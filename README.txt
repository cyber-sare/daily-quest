# Daily Quest 💜

Mini habit tracker diario pensado para navegador de celular.

## Incluye
- Casillas interactivas.
- Reinicio automático al cambiar de día.
- Historial de hasta 30 días visibles.
- Racha de días con 50% o más.
- Días completados al 100%.
- Promedio histórico.
- Mensajitos que cambian según el progreso.
- Datos guardados localmente en el navegador con `localStorage`.
- Diseño responsive para celular y computadora.

## Para cambiar las tareas
Abre `index.html` con un editor de texto y busca `const TASKS = { ... }`.
Puedes cambiar o agregar frases dentro de cada categoría.

## Para usarlo en el celular
La forma más cómoda es subir estos archivos a un servicio de páginas estáticas como GitHub Pages, Netlify o Cloudflare Pages y abrir el enlace desde el celular.
