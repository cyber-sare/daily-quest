- Hoy evité = 10% del progreso (con máximo de 3)
- Comiditas = sin puntos
- "Hoy cociné!" agregado a Extras
- Peluche hija flotante en la esquina inferior derecha
- Popup "Good Morning Everybunny" entre 9:00 y 10:59
- Historial + calendario visual del mes
- Logros
- Estado de ánimo
- "Algo bueno de hoy"
- Botón "Hoy fue difícil"
- Botón de mini misión aleatoria
- Isagi reactivo
- Espacio listo para la playlist (faltan los audios o links)

Para actualizar GitHub Pages:
1) Reemplaza el index.html de tu repo por este nuevo.
2) Sube también:
   - isagi.png

   - good_morning_everybunny.jpg
3) Espera unos segundos y recarga tu página.
