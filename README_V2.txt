Para actualizar GitHub Pages:
1. Sube/reemplaza index.html en la raíz del repositorio.
2. Sube isagi.png a la MISMA carpeta donde está index.html.
3. No borres otros archivos si ya los tienes.
4. Espera unos segundos y recarga tu link de GitHub Pages.

IMPORTANTE:
Si conservas el mismo dominio/repositorio, el localStorage del navegador sigue intacto, por lo que las casillas guardadas no deberían borrarse solo por actualizar el HTML.
